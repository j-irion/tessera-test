\section*{2. Prepared patches and experiment setup}
\begin{itemize}
	\item Area-averaged native 10 m TESSERA embeddings onto each original 30 m HyBiomass grid, retaining all 128 channels. Required full contributing-area validity; invalid inputs were zero-filled and affected GEDI labels were masked.
	\item Used the same prepared target arrays, target normalization and source-tile split for TESSERA and EnMAP. EnMAP retained all 202 original bands, normalized using training-only band statistics.
\end{itemize}

\begin{itemize}
	\item Both models use the same U-Net, masked per-patch RMSE loss, batch size 4, Adam $10^{-4}$, BF16 and 80 epochs. The best-validation checkpoint was evaluated on the held-out test set with predictions clipped to zero.
	\item Pixel-weighted RMSE pools all valid test pixels. Mean patch RMSE first computes RMSE within each patch, then weights all patches equally.
\end{itemize}

\section*{5. AlphaEarth experiment}
\begin{itemize}
	\item Dequantized 64-channel annual embeddings with $\mathrm{sign}(x)(x/127.5)^2$, area-averaged them onto the exact 30 m patch grids, and normalized each vector to unit Euclidean length.
	\item The U-Net uses the same splits and training settings as TESSERA, with 64 input channels. A real GPU pilot completed; full training and results are pending.
\end{itemize}

\section*{6. Limitations}
\begin{itemize}
	\item One split and seed per completed model; no uncertainty intervals. The test set has already been inspected, so it should not be used repeatedly for tuning.
	\item EnMAP was trained from scratch. Source-tile grouping does not guarantee independent geographic holdouts; Africa's 400+ bin has only 59 labels.
	\item TESSERA's BioMassters result is not directly comparable because its dataset, labels, resolution and splits differ from HyBiomass.
\end{itemize}
