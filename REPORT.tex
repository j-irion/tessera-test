\section*{1. Aim and current status}
\begin{itemize}
  \item Goal: predict above-ground biomass density (AGBD) from HyBiomass using pretrained satellite embeddings instead of only its EnMAP imagery.
  \item Compared: TESSERA v1.1 embeddings, original EnMAP bands, and a constant training-mean baseline.
  \item Main result: TESSERA + U-Net achieved 76.34 Mg/ha test pixel RMSE versus 89.18 Mg/ha for EnMAP + U-Net.
  \item AlphaEarth: matched preparation is running; training and results are pending.
\end{itemize}

\section*{2. Data gathering}
\begin{itemize}
  \item HyBiomass source: DLR EOC GeoService, following account registration and acceptance of the scientific-use license.
  \item Downloaded all seven regional archives directly on siena09: about 202 GiB compressed.
  \item Used authenticated HTTP downloads; final downloads used aria2, one archive at a time, up to four connections per archive.
  \item All seven archives matched DLR's published MD5 checksums.
  \item Each patch is a georeferenced $128\times128$ raster at 30 m in a local UTM CRS.
  \item Channels: 202 EnMAP bands, GEDI-derived AGBD at band index $-2$, and plant functional type at $-1$.
  \item GEDI labels are sparse estimates, not dense field measurements. Only valid labeled pixels contribute to training and metrics.
  \item TESSERA v1.1/dclimate embeddings were read from the public annual Zarr/Icechunk store. No foundation-model inference was run locally.
  \item AlphaEarth annual COGs and their public Parquet index were accessed from Source Cooperative; no Earth Engine credentials were required.
\end{itemize}

\section*{4. Matched data preparation}
\begin{itemize}
  \item Read TESSERA on its native 10 m grid; area-averaged vectors directly onto each original 30 m HyBiomass grid.
  \item Kept all 128 TESSERA channels and spatial context. No arbitrary array-index $3\times3$ pooling.
  \item Required full contributing-area validity. Invalid CNN inputs were zero-filled; affected GEDI labels were masked.
  \item Kept the original 202 EnMAP bands; computed band means and standard deviations from training patches only.
  \item Used exactly the same prepared target arrays, split manifest and target normalization for TESSERA and EnMAP.
\end{itemize}

\section*{5. Training setup}
\begin{itemize}
  \item Model: two-stage U-Net with 256/512 encoder channels and a 1024-channel bottleneck; one AGBD output.
  \item Input width: 128 channels for TESSERA; 202 for EnMAP. EnMAP was trained from scratch.
  \item Loss: masked per-patch RMSE, averaged over each batch. Target mean/std came from training labels only.
  \item Training: seed 42, batch size 4, Adam learning rate $10^{-4}$, BF16 autocast, 80 epochs, one GPU reported as NVIDIA L40.
  \item Split: source-tile-grouped 70/20/10 scheme. Exact counts are below.
  \item Checkpoint selection: lowest validation mean patch RMSE. Test predictions were clipped to zero.
\end{itemize}

\section*{8. AlphaEarth experiment}
\begin{itemize}
  \item Source: public annual AlphaEarth Satellite Embedding V1 COGs and Parquet index on Source Cooperative.
  \item Each 10 m pixel has 64 channels, $A00$--$A63$; annual years are matched to the EnMAP year.
  \item Dequantization: $\mathrm{sign}(x)(x/127.5)^2$; $-128$ is masked.
  \item Remote band chunks are fetched in parallel, then area-averaged onto the exact 30 m HyBiomass grid.
  \item Aggregated vectors are normalized to unit Euclidean length following Google's downsample guidance.
  \item Model and training settings match the other runs, except the required 64-channel first convolution.
  \item A real 12-patch GPU pilot completed with batch size 4 and about 1.05 GiB allocated memory.
  \item Full preparation started on 27 November 2026; full training and results are pending.
\end{itemize}

\section*{9. Limitations}
\begin{itemize}
  \item One split and seed per completed model; no uncertainty intervals yet.
  \item Current test results have been inspected; avoid repeated test-set tuning.
  \item Source-tile grouping does not guarantee independent geographic holdouts.
  \item TESSERA and EnMAP differ in pretraining, sensors and temporal information; the comparison does not isolate the cause of the gap.
  \item The TESSERA BioMassters result (27.43 Mg/ha mean patch RMSE) is not directly comparable: different dataset, labels, resolution and splits.
  \item Africa's 400+ bin has only 59 labels; small or spatially correlated samples may be unstable.
  \item Next checks: repeated initialization seeds, a separate geographic holdout, and completion of the matched AlphaEarth run.
\end{itemize}
